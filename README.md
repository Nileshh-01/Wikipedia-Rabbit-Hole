# Wikipedia Rabbit Hole

Wikipedia Rabbit Hole is a browser-based game built with HTML, CSS, and JavaScript. The goal is to navigate from a starting Wikipedia article to a target article by following related pages.

The game uses the Wikipedia API to dynamically load article information, images, descriptions, and related links. Players can choose between different difficulty levels, with each move increasing the rabbit-hole depth until they either reach the target or run out of moves.

## Features

- Randomly selected popular Wikipedia articles
- Dynamic related-article navigation
- Easy, Medium, and Hard difficulty levels
- Rabbit-hole depth tracking
- Win and lose states
- Dynamic article images and descriptions

## Built With

- HTML
- CSS
- JavaScript
- Wikipedia API
